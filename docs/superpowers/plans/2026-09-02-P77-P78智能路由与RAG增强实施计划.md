# P77/P78 智能路由与 RAG 增强 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立通用多意图路由，并把 RAG 升级为查询增强、多查询融合与真实 Cross-Encoder 重排链路。

**Architecture:** 使用独立纯策略组件完成意图规划、查询变体和候选融合，Chat 与 Knowledge Service 只负责流程编排。真实重排通过可替换 HTTP 适配器调用模型供应商，失败时显式降级到已有规则重排。

**Tech Stack:** Java 21、Spring Boot 3.3、MyBatis-Plus、Jackson、Java HttpClient、Vue 3、TypeScript、Flyway、JUnit 5。

**Spec:** `docs/superpowers/specs/2026-09-02-P77-P78智能路由与RAG增强设计.md`

## Global Constraints

- Java 类、字段、方法和方法内主要逻辑必须有中文注释。
- 数据库表和字段必须包含中文注释。
- 每次项目修改必须同步更新根目录 `README.md`，但不得写入验证记录。
- 后端代码修改后不得自动启动服务。
- 现有 API 保持向后兼容，新增请求字段必须有默认值。
